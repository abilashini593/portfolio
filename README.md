# Developer Portfolio

Modern developer portfolio showcasing full-stack projects, real-time applications, and scalable software solutions built using React, Node.js, MongoDB, and modern web technologies.

## Tech Stack

- React.js
- Vite
- Framer Motion
- CSS3
- Lucide React

## Features

- Responsive UI
- Smooth animations
- Project showcase section
- Skills & achievements section
- Contact integration
